# section-v1 transport

Generation-window images for the St. George to Stapleton section of the Staten Island painted map, served here only so the creative connector can fetch them by URL. Each file is one 1024 px window (`output/pilot-c02-v1/tiles/<T>/quadrants/<C>/context_ortho.png` in the map-tile-workflow repository): the already painted neighbours and the aerial quadrant to paint next. The ledger in that repository records which image fed which attempt, by sha256.

Painted from (c) City of New York / NYC OTI 2024 orthophotos, CC BY 4.0.
